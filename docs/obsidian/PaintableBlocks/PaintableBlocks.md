# PaintableBlocks

Mod para Minecraft **26.2**, con **NeoForge 26.2.0.88**. Permite recortar bloques subdivididos y pintar independientemente sus superficies con texturas decorativas.

Esta documentación recoge el planteamiento acordado y sus ampliaciones aceptadas para el mod. Describe requisitos; no acredita que estén implementados o probados en el juego.
