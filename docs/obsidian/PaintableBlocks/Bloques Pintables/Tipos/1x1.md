# 1×1

Cada lado completo contiene **1 cuadrado pintable**. El bloque está compuesto por **1 subcubo**, con una longitud de un bloque por arista.

Pintar un cuadrado consume **256 unidades**. Una cara completa consume 256 unidades.

[[Reglas Generales]] · [[Conversión de Subdivisiones]]

No admite recortes con martillo, mazo o cincel. Sí admite pintura, limpieza y recolección.
