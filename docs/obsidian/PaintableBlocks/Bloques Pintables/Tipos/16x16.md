# 16×16

Cada lado completo contiene **256 cuadrados pintables**. El bloque está compuesto por **4096 subcubos**, con una longitud de 1/16 de bloque por arista.

Pintar un cuadrado consume **1 unidades**. Una cara completa consume 256 unidades.
