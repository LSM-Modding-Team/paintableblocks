# Reglas generales

Los bloques se subdividen en subcubos tridimensionales. La denominación indica cuántos cuadrados pintables hay por eje en cada lado: un bloque de 4×4 tiene 16 cuadrados por lado y 64 subcubos.

Cada superficie expuesta se puede pintar independientemente, incluidas las superficies interiores descubiertas al retirar subcubos. La geometría cambia únicamente al retirar subcubos. Los recortes son irreversibles y no devuelven materiales ni pintura. Al retirar el último subcubo, el bloque desaparece.

La colocación tiene una lógica similar a la de las escaleras. El bloque completo comparte una orientación para sus pinturas; forma y pinturas se orientan conjuntamente. Véase [[Texturas y Orientación]].

Las reglas para recoger y copiar diseños están en [[Recolección y Conservación]].
